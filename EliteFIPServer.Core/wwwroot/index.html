Presentation

Select ⚙ on the dashboard to arrange panels, then ☰ for layout settings: choose Passive display for an unattended screen, or Interactive touch for phones and tablets. Use ⛶ for full screen.

Each browser remembers its own settings. To keep separate arrangements on one device, add ?layout=name to the address, for example /Dashboard.html?layout=tablet.
