- **Gotcha for future dashboard verification:** the dashboard's tablet layout only activates via `matchMedia("(hover: none) and (pointer: coarse)")` or `innerWidth <= 760` (`CockpitDashboard.js:60-64`, `Dashboard.css:154-160`). Resizing a desktop/non-touch browser to tablet widths does **not** trigger it — you must explicitly set the dashboard's `#presentation-mode` dropdown to "Interactive tablet" before measuring, or the check silently validates the wrong (12-column "display") layout.
- **Playwright MCP fix:** `.mcp.json` now passes `--browser=chromium` to `@playwright/mcp`. Without it, the MCP server defaults to the "chrome" channel, which needs system Google Chrome — installing that failed here for lack of admin rights. The bundled Playwright Chromium works fine once pinned explicitly. Changing `.mcp.json` requires an MCP reconnect (VS Code restart worked; a lighter reload may also work but is untested).
- **Panel server autostart:** `AutostartPanelServer` is a persisted user setting (Settings → "Start Panel Server automatically", off by default in a fresh profile). A running `EliteFIPServer.exe` with port 4545 not listening is expected, not a bug, until that toggle (or a manual start) is used.
- **New agent added:** `.claude/agents/elite-build-runner.md` — runs the stop/test/build/restart lifecycle and reports back only totals/PID/URL, keeping raw MSBuild/signing/test output out of the main conversation. Referenced by name in both [CLAUDE.md](../CLAUDE.md) and [.github/copilot-instructions.md](../.github/copilot-instructions.md) so it's actually invoked going forward, alongside the existing `elite-architecture-reviewer` and `elite-dashboard-verifier`.
